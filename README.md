## 📱 웹앱 소개 및 주요 기능 (Features)

스마트폰이나 태블릿의 웹 브라우저를 통해 실시간으로 다인 플레이어 베팅과 라운드 자동 정산을 수행할 수 있습니다.

- **간편한 입장**: 별도의 회원가입이나 로그인 없이 6자리 방 코드 입력만으로 즉시 참여
- **실시간 베팅 보드**: 정규 순위 베팅(67칸) 및 특수 카드(조건부 베팅, 극적인 마무리) 지원
- **오터치 방지 인터랙션**: 0.25초 롱프레스 링 또는 더블 탭으로 실시간 광클 시의 오터치 방지 및 햅틱 피드백
- **협동형 실시간 정산**: 방장의 경주 결과 입력과 정산 계산이 모든 플레이어 화면에 실시간 동기화
- **1인칭 결과 필터 (`⭐ 내 결과만`)**: 복잡한 보드판에서 내 베팅 칩의 적중/실패 여부와 상세 계산식을 원터치로 확인
- **32종 VIP 클럽 카드 자동 정산**: 주사위 비례 배당, 색상별 승수 보너스, 편승 베팅, 파산 방지 하한선($0) 완벽 적용

## 🎲 사용 가이드 (How to Play)

1. **방 생성 (방장)**: 메인 화면 하단의 [새 방 만들기]를 통해 방을 생성합니다 (6자리 방 코드 발급).
2. **플레이어 입장**: 동호회원 및 친구들은 각자의 스마트폰에서 6자리 코드를 입력하고 원하는 닉네임과 칩 도형을 선택합니다.
3. **경주 및 실시간 베팅**: TV나 태블릿에서 **공식 컴패니언 앱**의 경주 중계를 시청하며, 스마트폰 화면의 보드판 빈 슬롯에 실시간으로 토큰을 놓아 베팅합니다.
4. **베팅 마감**: 3번째 말이 빨간 선을 넘으면 방장이 `[🛑 베팅 마감]`을 선언합니다.
5. **결과 입력 및 정산**: 1위 말이 결승선에 도착하면 방장이 각 말의 최종 위치를 입력하고, 전 플레이어가 실시간으로 자동 정산된 결과를 확인합니다.
